# Streampulse & Yailen TV

Aplicación unificada que combina el panel financiero, de inversión y materiales de Streampulse (Mangoreel clone con soporte Nequi / USDT) y la plataforma interactiva de videos cortos de **Yailen TV** (*APRENDE CON YAILEN* y *Wanketeros MEQUE KIDS*).

## 🚀 Despliegue en GitHub Pages
1. Sube todos estos archivos a tu repositorio en GitHub.
2. Ve a **Settings > Pages** y activa la rama `main`.
